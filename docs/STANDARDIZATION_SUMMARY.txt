PROBLEM IDENTIFIED:
-------------------
Your production system has inconsistent bill structures:
  • Old tenants: Bills contain Rent + Deposit (e.g., KES 12,500 = 6,500 + 6,000)
  • New bills: Bills contain Rent only (e.g., KES 6,500)
  • This causes confusion and incorrect financial reporting

ROOT CAUSE:
-----------
1. TenantController.php (line 312-314): Creates initial bills with Rent + Deposit
2. BillController.php (line 177-185): Creates monthly bills with Rent only
3. Result: Two different bill structures in the same system

SOLUTION IMPLEMENTED:
---------------------

1. SQL MIGRATION CREATED:
   File: backend/database/migrations/standardize_bill_structure.sql
   Purpose: Fix existing data in production

2. CODE FIX APPLIED:
   File: backend/app/Controllers/TenantController.php
   Change: Removed Deposit line item from initial tenant bills
